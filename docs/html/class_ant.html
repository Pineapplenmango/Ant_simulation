Detailed Description

Repræsenterer en individuel myre i simulationen.

Anten bevæger sig på et grid, påvirket af feromonstyrker og tilfældige valg. Hvis den finder en ressource, vil den bevæge sig tilbage mod reden og aflejre feromoner på sin vej.

Parameters
positionXMyrens nuværende X-position i gridet.
positionYMyrens nuværende Y-position i gridet.
carryingRessourceTrue, hvis myren bærer en ressource tilbage.
